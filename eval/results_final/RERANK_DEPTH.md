# Rerank-depth study (rrf_bge, fixed search)

The shipped engine scores **all** fused candidates (up to 100) and keeps the best 24 in reranked order. Here the reranker scores only the first N fused candidates. Same questions for every depth; Δ = depth N minus all, paired bootstrap 95% CI. `no rerank` = the merged list without the reranker. Rerank p50 = median reranker call time (a call recorded when the answer was first computed; it includes the network path to the self-hosted GPU, so use it only to compare depths).
